# Atlas de modelos mentales

Web interactiva con 80 modelos mentales clasificados por temas (mente, sesgos, individuo, equipo, organización, sociedad, decisión, proyectos, liderazgo y educación). Cada modelo tiene un esquema SVG animado, una explicación y, en muchos casos, un ejercicio práctico para el aula.

## Estructura

- `index.html`: página principal
- `css/styles.css`: estilos, tipografías y animaciones
- `js/app.js`: datos base, plantillas de dibujo y lógica de la interfaz
- `js/extensions.js`: modelos añadidos, ejercicios, estilo a mano alzada y pie de página

## Publicar en GitHub Pages

1. Sube todo el contenido de esta carpeta a la raíz del repositorio.
2. En *Settings → Pages*, elige la rama `main` y la carpeta `/ (root)`.
3. Tras un minuto la web estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

Para verla en local, abre `index.html` o usa `python3 -m http.server`.
